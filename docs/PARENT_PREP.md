# Parent prep sheet

One page listing every Harry Potter scene in the nine nights, so you can find them in your own copies of the books and films before each night. The app has no video links. It is shown in the app (from the map) and can be printed.

Every reference is copied from the night files (`docs/nights/night-N.md`, the "Reference" line of each scene). Chapter numbers follow the UK editions. On a **short evening**, only the first scene of each night is used.

**Intensity:** *gentle*, *some peril* or *intense* (a death, killing or deep grief). Intense scenes have a note for the parent in the app; read it before the night.
